# Workshop Portal Operations

## Car-Based Service Workflow Guide

## Who Should Read This?

- Workshop Portal Users
- Workshop Supervisors
- Service Estimation Teams
- Company Operations and Procurement Teams

## 1. What Is Workshop Portal Used For?

Workshop Portal is used by workshop partners to process assigned vehicle service requests from intake to completion updates.

Core actions include:

- View cars and assigned requests
- Perform and update inspections
- Review required work and parts
- Submit service/parts quotations
- Receive approval and start execution
- Update progress and completion status

## 2. Workflow Start Point

The workflow starts when a workshop request is assigned by company operations.

Typical path:

Workshop Portal -> Cars/Requests -> Inspection -> Required Work/Parts -> Submit Quote -> Approval -> Start Work -> Final Inspection -> Complete

Each request should stay linked to customer, car, and service reference.

## 3. Step-by-Step Workshop Flow

### Step 1: Open Cars or Assigned Requests

- Login to Workshop Portal
- Open assigned cars or service requests
- Select target request

Review:

- Vehicle details
- Request/lead reference
- Required timeline
- Branch/location context

### Step 2: Review Required Work and Parts

- Open request detail
- Review required service scope
- Review parts required for execution
- Validate technical feasibility and lead time

### Step 2.1: Perform Inspection Process

Before final quoting or execution, workshop should complete inspection steps:

- Open inspection from the assigned request/car context
- Record technical findings and issue severity
- Identify required parts and labor scope
- Submit inspection findings for review/approval (if configured)

Inspection output is the technical base for quotation and job execution.

### Step 3: Submit Workshop Quote

For each request, submit:

- Labor/service quote
- Parts quote (if applicable)
- Delivery/turnaround timeline
- Notes and technical conditions

After submit:

- Quote moves to review queue
- Company team compares/approves
- Status updates become visible in portal

### Step 4: Receive Approval and Confirm

If approved:

- Confirm acceptance
- Confirm execution schedule
- Prepare for job start

If revision is requested:

- Update quote details
- Resubmit

### Step 5: Start Work

- Move request to `In Progress`
- Start execution by approved scope
- Record parts usage and work notes

### Step 6: Update Progress and Complete

- Update milestone/status as work progresses
- Perform final/post-repair inspection
- Mark request ready for final review
- Submit as completed when work is done

## 4. Typical Workshop Status Flow

- Assigned
- Quote Pending
- Quote Submitted
- Under Review
- Approved
- In Progress
- Waiting for Parts
- Completed
- Closed

Use consistent status updates to keep operations dashboard accurate.

## 5. Rules and Restrictions

- Do not start work before quote approval (unless emergency policy exists)
- Do not skip initial inspection before final quote
- Do not mark complete without post-repair/final inspection
- Do not change approved scope without formal revision
- Do not mark complete without final verification
- Keep all notes and status transitions traceable
- Maintain SLA response for quote and progress updates

## 6. Verification with Operations Team

Company operations should be able to verify:

- Request assignment is correct
- Quote status is current
- Work progress is updated in real time
- Completion is supported with notes/evidence

This keeps workshop and company teams synchronized.

## 7. Simple Summary

Workshop Portal flow:

Open Car/Request -> Review Work and Parts -> Submit Quote -> Approval -> Start Work -> Complete

It ensures partner workshop execution is controlled, transparent, and aligned with automotive service operations.
