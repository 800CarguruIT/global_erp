# Company User Management

## Company Access Control Guide

## Who Should Read This?

- Company Administrators
- Security Administrators
- Operations Managers responsible for user access

## What Is This Page Used For?

The Company User Management page allows company-level administrators to control who can access the company’s system environment.

Through this page, you can:

- View all company users
- Add new users
- Edit existing users
- Activate or deactivate users

This ensures that only authorized employees have access to company operations inside the Global ERP system.

## Why This Is Important

Proper user control at the company level:

- Protects company data
- Prevents unauthorized access
- Ensures accountability
- Supports operational security
- Maintains clean access structure

## A. Viewing Company Users

### What You Can See

The users list typically shows:

- Full name
- Email address
- Assigned role
- Account status (Active / Inactive)
- Last activity (if available)

### Why This Matters

This view allows administrators to:

- Confirm who has system access
- Check whether users are active
- Identify inactive or outdated accounts
- Review role assignments

You should always be able to clearly identify who has access to company operations.

## B. Creating a New Company User

### When to Create a User

Create a user when:

- A new employee joins the company
- An existing employee requires system access
- A new manager or supervisor needs access

### Required Information

When creating a user, you will provide:

- Full name
- Email address (usually the unique identity)
- Mobile number (if required)
- Assigned role
- Initial password (if required)
- Account status (normally set to Active)

After saving, confirm the user appears in the list.

### Best Practice

- Assign the correct role based on job responsibility
- Follow password policy requirements
- Share login credentials securely
- Encourage password change at first login (if required)

## C. Editing a Company User

### When to Edit a User

You may need to edit a user when:

- Role changes
- Contact information changes
- Promotion or department transfer
- Data correction is required

### What Can Be Updated?

- Name
- Mobile number
- Assigned role
- Other profile information

### Important Note

The email address is usually treated as the user’s unique identifier.
Change it carefully to avoid login or identity issues.

After editing, verify the changes are correctly reflected in the list.

## D. Managing User Status (Active / Inactive)

### When to Deactivate a User

- Employee leaves the company
- Temporary suspension
- Security concern
- Role no longer requires system access

### Why Deactivate Instead of Delete?

Deactivating a user:

- Preserves historical transaction records
- Maintains audit trail
- Prevents data loss
- Blocks login access

Deleting users can remove important accountability history.

### Reactivating a User

If a user returns or access is restored:

- Change status back to Active
- Confirm login works correctly

## E. Validation Checklist

After creating, editing, or changing status, confirm:

- The user appears correctly in the list
- The correct role is assigned
- Active users can log in successfully
- Inactive users cannot access protected areas
- Access follows the least-access principle

## Security & Access Control Notes

To maintain a secure company environment:

- Review company users regularly
- Remove unnecessary access immediately
- Limit high-level access roles
- Document reasons for major role or status changes
- Apply least-privilege access at all times

## Simple Summary

Company User Management allows company administrators to:

- Control employee access
- Assign appropriate roles
- Protect operational data
- Maintain accountability

It is a critical function for secure and structured operations within the Global ERP system.
