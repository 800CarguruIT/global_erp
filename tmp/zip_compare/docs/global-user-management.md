# Global User Management

## Business Guide for Administrators

## Who Should Read This?

- Global Administrators
- Security or IT Administrators
- Anyone responsible for managing user access across the organization

## What Is Global User Management?

Global User Management is the area of the system where administrators control who can access the platform.

It allows you to:

- Create new users
- Edit user information
- Assign roles and permissions
- Reset passwords
- Activate or deactivate accounts

This ensures the right people have the right access - and no one has access they should not.

## Why This Is Important

Proper user management:

- Protects sensitive company data
- Ensures accountability
- Maintains system security
- Supports audit and compliance requirements

User access should always be controlled centrally and reviewed regularly.

## A. Viewing and Searching Users

### What You Can Do

Administrators can:

- View all users across the system
- See whether users are active or inactive
- Check assigned roles
- Search and filter users

### Typical Use Cases

- Confirm whether someone already has access
- Verify a user�s role
- Review inactive accounts
- Audit who has global-level access

### Expected Outcome

You should be able to clearly see:

- User status (Active / Inactive)
- Assigned role
- Contact details

## B. Creating a New User

### When Do You Create a User?

Create a user when:

- A new employee joins
- A new global admin is assigned
- A new authorized stakeholder needs access

### Information Required

To create a user, you must provide:

- Full name
- Email address (this usually acts as the unique identity)
- Mobile number
- Initial password
- Account status (normally set to Active)
- Assigned role

### Important Notes

- The email address should be accurate and unique.
- The assigned role determines what the user can access.
- Passwords must follow security policy.

### Best Practice

After creating a user:

- Share login details securely
- Instruct the user to change their password at first login (if required by policy)

## C. Editing an Existing User

### When Would You Edit a User?

You may need to update a user when:

- Their phone number changes
- Their name needs correction
- Their role changes
- They are promoted or reassigned

### What Can Be Updated?

- Full name
- Mobile number
- Assigned role
- Status

### Important Consideration

The email address is typically treated as the user�s unique identity.
Changing it should be done carefully to avoid access issues.

## D. Resetting or Changing a Password

### When Is Password Reset Used?

- User forgot password
- Security concern
- Compliance requirement
- Account compromise suspected

### What Happens During Reset?

- A new password is set or generated
- The user receives new login credentials
- They may be required to change it upon next login

### Security Checklist

Before confirming reset:

- Ensure the new password meets strength requirements
- Communicate credentials securely
- Never share passwords via insecure channels

## E. Activating or Deactivating a User

### When to Deactivate a User

- Employee leaves the company
- Temporary suspension
- Security concern
- Role no longer required

### Why Deactivate Instead of Delete?

Deactivating:

- Preserves activity history
- Maintains audit trail
- Keeps past records intact
- Prevents login access

Deleting a user can remove important traceability.

### Best Practice

Always deactivate instead of deleting unless there is a specific technical reason.

## F. Final Validation Checklist

After creating or modifying a user, confirm:

- The user appears correctly in the list
- The correct role is assigned
- Active users can log in successfully
- Inactive users cannot access protected areas
- Password policy is enforced

## Operations Control and Security Principles

- Access should follow the principle of �least privilege� - give only the access required.
- Regularly review active users.
- Immediately deactivate users who leave the organization.
- Maintain documentation for audits.

## Summary

Global User Management ensures:

- Controlled access to the platform
- Clear role-based permissions
- Secure authentication
- Full accountability through audit trails

It is a critical security and operations control function within the Global ERP system.
