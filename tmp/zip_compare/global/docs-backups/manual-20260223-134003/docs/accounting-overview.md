# Accounting Overview

## Who Should Read This?

- Finance managers
- Accounting users
- Leadership reviewing financial performance

## Purpose

Explain how operational transactions flow into accounting and reporting.

## Core Accounting Components

- Chart of accounts
- Journals and journal lines
- Invoices and collections
- Cost allocation and reconciliation
- Financial statements (P&L, balance sheet, cashflow)

## How Operations Feed Accounting

1. Jobs and invoices generate revenue-side entries.
2. Procurement and inventory usage generate cost-side entries.
3. Payments and settlements update receivables/payables.
4. Period-end checks validate balances before reporting.

## Monthly Close Checklist

1. Reconcile open invoices
2. Validate stock-related cost postings
3. Review unmatched or manual journal entries
4. Confirm branch and company-level rollups
5. Publish management reports

## Controls

- Role-based posting permissions
- Approval for high-impact manual journals
- Audit trail for edited/deleted entries
- Period lock after close

## Key Reports

- P&L by period
- Balance sheet snapshot
- Cashflow summary
- Account statement drill-down
