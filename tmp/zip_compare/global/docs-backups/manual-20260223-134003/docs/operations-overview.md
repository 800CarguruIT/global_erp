# Operations Overview

## Who Should Read This?

- Company admins
- Branch managers
- Operations leads

## Purpose

This guide explains how daily operations run in Global ERP from intake to completion.

## Daily Workflow (Simple)

1. Lead intake and qualification
2. Inspection and estimate
3. Job planning and execution
4. Parts procurement (if needed)
5. Inventory issue and usage tracking
6. Invoice and payment processing
7. Reporting and closure

## Operating Rules

- Every customer-facing action should map to a record (lead, inspection, job card, invoice).
- Status changes should be explicit and traceable.
- Do not skip approval steps for cost-impacting actions.
- Use branch ownership rules to avoid cross-branch data confusion.

## Key Dashboards

- Operations dashboard
- Workshop jobs board
- Procurement tracker
- Inventory stock/transfer board
- Revenue and accounting summaries

## Success Metrics

- Lead-to-job conversion
- Job turnaround time
- Parts availability rate
- Invoice collection cycle
- Rework/reopen ratio

## Common Mistakes To Avoid

- Creating jobs before inspection scope is finalized
- Issuing parts without proper location tracking
- Closing jobs before all billable lines are verified
- Delayed status updates causing false reporting
