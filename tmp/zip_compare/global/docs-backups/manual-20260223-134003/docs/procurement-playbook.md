# Procurement Playbook

## Who Should Read This?

- Procurement teams
- Inventory controllers
- Vendor management teams

## Purpose

Define a simple, auditable procurement flow from requirement to receipt.

## End-to-End Procurement Flow

1. Raise requirement
2. Send vendor inquiries / request quotes
3. Compare bids
4. Approve vendor and issue PO
5. Receive goods and reconcile against PO
6. Move approved stock into inventory
7. Close PO and report spend

## Approval Controls

- Value-based approval thresholds
- Mandatory vendor selection rationale for exceptions
- Change control for PO quantity/price updates

## Vendor Performance Checklist

- Response time
- Fill rate
- Delivery reliability
- Price consistency
- Return/defect frequency

## Documents To Keep Linked

- Inquiry reference
- Vendor quote
- Purchase order
- Goods receipt evidence
- Invoice and payment records

## Common Failure Points

- PO created without finalized requirement
- Goods received without PO linkage
- Delayed GRN causing stock mismatch
- Vendor quote updates not reflected before PO issue
