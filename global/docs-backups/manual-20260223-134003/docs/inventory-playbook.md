# Inventory Playbook

## Who Should Read This?

- Inventory managers
- Procurement users
- Branch operations teams

## Purpose

Provide a clear process for receiving, moving, issuing, and reconciling stock.

## Core Inventory Cycle

1. Create or import item master
2. Receive stock into a valid location
3. Track movements (transfer, issue, adjustment)
4. Reconcile on-hand quantities
5. Report low-stock and aging items

## Rules That Matter

- Stock must always exist in a physical location.
- Every movement requires a source/destination context.
- Manual adjustments should include reason and actor.
- Do not issue stock without a linked operational reference when applicable.

## Minimum Data Quality Checklist

- Item code is unique and searchable
- Unit of measure is consistent
- Location hierarchy is maintained
- Reorder threshold is configured for fast-moving items

## Operational Alerts

- Negative stock risk
- Reorder threshold breached
- Slow-moving inventory
- Repeated adjustments on same SKU

## Weekly Routine

1. Review stock variance report
2. Validate pending transfer orders
3. Verify open procurement receipts
4. Confirm high-value item balances
